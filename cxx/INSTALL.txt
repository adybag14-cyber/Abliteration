abliterate-cxx — no Python, no GPU for the first hour.

1. Download a row from
   https://github.com/adybag14-cyber/Abliteration/releases/tag/cxx-nightly

2. Download SHA256SUMS and verify the selected archive before extraction.
   Copy-ready Get-FileHash / sha256sum / shasum commands are in
   GETTING-STARTED.md and on the deployed #lab workbench.

3. Unpack so GETTING-STARTED.md sits next to the binary (flattened archive
   root). examples/ must sit next to the exe.

   Windows — zip contents are at archive root (exe next to GETTING-STARTED.md):

     Expand-Archive -Path abliterate-cxx-windows-x64-msvc.zip -DestinationPath abliterate-cxx-1.1.0
     Set-Location abliterate-cxx-1.1.0
     .\abliterate-cxx.exe guide
     .\abliterate-cxx.exe doctor
     .\abliterate-cxx.exe limits
     .\abliterate-cxx.exe self-check
     .\abliterate-cxx.exe demo

   If you used Expand-Archive without -DestinationPath, cd into the zip-stem
   folder (abliterate-cxx-windows-x64-msvc). The exe is immediately there —
   no extra nested folder. Then run the same five commands.

   Linux — tar, then cd into the wrapper folder:

     mkdir abliterate-cxx-1.1.0 && tar -xzf abliterate-cxx-linux-x64-gcc16.tar.gz -C abliterate-cxx-1.1.0
     cd abliterate-cxx-1.1.0
     chmod +x ./abliterate-cxx
     ./abliterate-cxx guide
     ./abliterate-cxx doctor
     ./abliterate-cxx limits
     ./abliterate-cxx self-check
     ./abliterate-cxx demo

   macOS — tar, then cd into the wrapper folder:

     mkdir abliterate-cxx-1.1.0 && tar -xzf abliterate-cxx-macos-arm64-llvm.tar.gz -C abliterate-cxx-1.1.0
     cd abliterate-cxx-1.1.0
     xattr -d com.apple.quarantine ./abliterate-cxx
     ./abliterate-cxx guide
     ./abliterate-cxx doctor
     ./abliterate-cxx limits
     ./abliterate-cxx self-check
     ./abliterate-cxx demo

4. Run, in this order (Hour 0):

     abliterate-cxx guide
     abliterate-cxx doctor
     abliterate-cxx limits
     abliterate-cxx self-check
     abliterate-cxx demo

   Hour 0.5: estimate dim → apply orba-directional → eval toys → recipes.

5. doctor must print  cplusplus=202400

6. Then GETTING-STARTED.md  (same folder).

Each compiler/OS pair has its own filename. See SHA256SUMS on the release.
